# Storico DNA

Questa cartella contiene documentazione non piu canonica:

- audit tecnici;
- report incrementali di allineamento;
- note una tantum;
- snapshot storiche del progetto;
- documenti che hanno valore di contesto, ma non devono guidare il lavoro quotidiano prima del codice reale.

## Regola d'uso

- leggere questi file solo se servono contesto retrospettivo o decisioni storiche;
- non usarli come fonte primaria se il codice attuale dice altro;
- non riportare nel percorso canonico `DNA/` contenuti storici, verbosi o instabili senza una ragione operativa forte.
